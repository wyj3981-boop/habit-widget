# Habit Widget

Windows 바탕화면에 띄워 두는 작은 습관 트래커 위젯입니다.
설치 없이 Windows 10/11에 기본으로 들어 있는 PowerShell + WPF로 동작합니다.

## 기능

- **오늘 체크리스트**: 습관을 클릭해서 완료 표시, 진행률 막대
- **주간 잔디**: 습관마다 최근 7일 기록, 칸을 클릭해서 지난 날 수정
- **월간 잔디**: 그날 완료 비율에 따라 색이 진해지는 달력, 월 달성률 표시
- **습관 추가·삭제**: 입력칸에 입력 후 Enter로 추가, ✕ 버튼 또는 우클릭으로 삭제
- 드래그로 위치 이동, 항상 위에 표시, Windows 시작 시 자동 실행

## 실행 방법

1. 이 저장소를 내려받습니다. (**Code → Download ZIP** 후 압축 해제)
2. 폴더 안의 `HabitWidget.vbs`를 더블클릭합니다.

> `HabitWidget.vbs`와 `HabitWidget.ps1`은 반드시 같은 폴더에 있어야 합니다.
> 바탕화면에서 실행하려면 vbs 파일을 옮기지 말고 **우클릭 → 보내기 → 바탕 화면(바로 가기 만들기)**을 사용하세요.

실행되지 않으면 두 파일을 우클릭 → **속성 → 차단 해제**를 체크해 보세요.

## 사용법

| 동작 | 방법 |
| --- | --- |
| 오늘 완료/취소 | 체크박스 또는 습관 이름 클릭 |
| 지난 날 기록 수정 | 습관 오른쪽 7칸 클릭 |
| 습관 추가 | 아래 입력칸에 입력 후 Enter |
| 습관 삭제 | 줄 오른쪽 ✕ 클릭 또는 줄 우클릭 |
| 지난달 보기 | 월간 잔디의 ‹ › |
| 위치 이동 | 빈 곳을 드래그 |
| 설정 | 위젯 우클릭 → 항상 위에 표시 / 자동 실행 / 데이터 폴더 열기 / 종료 |

## 데이터

기록은 `%APPDATA%\HabitWidget\data.json`에 저장됩니다. 백업하려면 이 파일만 복사하면 됩니다.

## 파일 구성

- `HabitWidget.ps1`: 위젯 본체 (PowerShell + WPF)
- `HabitWidget.vbs`: 콘솔 창 없이 위젯을 실행하는 런처
